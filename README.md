# DiscountScout
Discount Scout 🎮  Steam oyun fiyatlarını anlık takip eden, indirimleri kaçırmamanız için analizler sunan ve güncel oyun haberlerini önünüze getiren şık bir masaüstü asistanıdır. Entegre USD/TRY hesaplayıcı ve mini Tetris oyunu içerir. Ayaz Er tarafından oyuncular için geliştirildi. 🚀
