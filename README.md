# 🎮 Discount Scout

**Discount Scout**, Steam oyun fiyatlarını anlık takip eden ve indirimleri kaçırmamanız için analizler sunan modern bir masaüstü asistanıdır.

## ✨ Özellikler
* **Anlık Takip:** Steam API ile güncel fiyatlar.
* **Haberler:** Oyun dünyasından canlı akış.
* **Hesaplayıcı:** Entegre USD/TRY kur çevirici.
* **Eğlence:** Yerleşik mini Tetris oyunu.

## 🚀 Kurulum
1. `tracker.py` dosyasını indirin.
2. `pip install customtkinter Pillow requests` komutuyla kütüphaneleri kurun.
3. Çalıştırın!
